# LiuEggy 个人网站

成都理工大学机械工程系学生的个人网站 - 嵌入式开发 | 机器视觉 | 三维设计

## 🌐 网站功能

- **个人主页** - 技能展示、实时时钟、博客预览
- **关于页面** - 个人介绍、技能详情、网站统计
- **博客系统** - Markdown编辑、文章管理、评论互动
- **留言板** - 访客留言、表情支持、回复功能
- **管理后台** - 内容发布、留言审核

## 🛠️ 技术栈

- **前端**: HTML5, CSS3, Vanilla JavaScript
- **后端**: PHP 8.2, MySQL 5.7
- **服务器**: Nginx + Cloudflare CDN
- **特性**: 响应式设计、暗色模式、Live2D看板娘

## 📂 核心文件

- `index.html` - 首页
- `about.html` - 关于页
- `guestbook.html` - 留言板
- `blog/` - 博客系统
- `admin/` - 管理后台
- `api/` - 后端接口
- `config/database.php` - 数据库配置
