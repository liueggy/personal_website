# 🔧 移动端留言问题修复

## 问题描述
- ✅ PC 电脑可以正常提交留言
- ❌ 手机浏览器提交留言显示"服务器错误"

## 问题分析

根据日志分析，发现iPhone移动端请求返回 **500 错误**：
```
172.68.174.86 - [21/Oct/2025:12:12:30] 
"POST /comments_db.php HTTP/2.0" 500 198
User-Agent: Mozilla/5.0 (iPhone; CPU iPhone OS 26_1_0...)
```

## 已实施的修复

### 1. 增强数据接收兼容性
```php
// 兼容移动端：如果 JSON 解析失败，尝试使用 $_POST
if (!is_array($body) || empty($body)) {
  $body = $_POST;
}
```

### 2. 添加详细的调试日志
所有请求信息现在会记录到：`/www/wwwlogs/comments_debug.log`

记录内容：
- 原始输入数据
- JSON 解析结果
- POST 数据
- Content-Type 头
- 所有错误和异常

### 3. 改进错误处理
添加了完整的错误追踪和日志记录

## 可能的原因

### 原因 1：Content-Type 不匹配
- PC 浏览器：正确发送 `application/json`
- 某些移动浏览器：可能发送 `application/x-www-form-urlencoded`

**解决方案**：已添加 $_POST 后备支持

### 原因 2：PHP 扩展缺失
- 某些移动请求可能触发了不同的代码路径
- 需要的 PHP 扩展可能未启用

### 原因 3：请求头问题
- 移动浏览器的请求头可能与 PC 不同
- CORS 或其他安全策略可能影响
